# Privacy Policy — Ultimate Web Redactor

Last updated: 2 August 2026

## Short version

This extension collects nothing, sends nothing, and talks to no server. Everything it
does happens inside your browser, on the page you are looking at.

## What is collected

Nothing. The extension does not collect, store, transmit or sell any user data.

Specifically, it does not collect any of the following: personally identifiable
information, health information, financial or payment information, authentication
information, personal communications, location, web history, user activity, or website
content.

## What is stored

Your settings only — the chosen mode (pixelate, blur, black out, red box), the block
size, blur radius, outline width, padding, corner radius, colour, and the lock switch.

These are written to `chrome.storage.local`, which lives on your own machine. They are
never uploaded. Removing the extension removes them.

## Network activity

None. The extension makes no network requests of any kind. It has no analytics, no
telemetry, no crash reporting, no accounts and no remote configuration.

## Page access

The extension requests no host permissions. It uses `activeTab`, which grants access to
a single tab only at the moment you invoke the extension — from the right-click menu, a
keyboard shortcut, or the toolbar popup. Nothing runs on pages you have not acted on.

When you do invoke it, the extension reads the layout of the page in order to place the
mosaic, blur, fill or outline. That reading happens locally and the result never leaves
your browser.

## Changes

Any change to this policy will be published in this file, in the repository below.

# プライバシーポリシー — Ultimate Web Redactor

最終更新日: 2026年8月2日

## 要点

この拡張機能は何も収集せず、何も送信せず、どのサーバーとも通信しません。処理はすべて
ブラウザの中、いま開いているページの上で完結します。

## 収集するもの

ありません。ユーザーデータの収集・保存・送信・販売のいずれも行いません。

具体的には次のいずれも収集しません。個人を特定できる情報、健康に関する情報、財務状況や
支払いに関する情報、認証に関する情報、個人的コミュニケーション、位置情報、ウェブ履歴、
ユーザーのアクティビティ、ウェブサイトのコンテンツ。

## 保存するもの

設定だけです。選んだモード（モザイク・ぼかし・黒塗り・赤枠）、ブロックサイズ、ぼかし半径、
枠の太さ・余白・角丸・色、クリック解除のロック。

これらは `chrome.storage.local` に書かれます。保存先はご自身の端末の中で、外部に送られる
ことはありません。拡張機能を削除すれば一緒に消えます。

## 通信

行いません。いかなる種類のネットワークリクエストも発生しません。解析も、テレメトリも、
クラッシュレポートも、アカウントも、リモート設定もありません。

## ページへのアクセス

ホスト権限を要求しません。使うのは `activeTab` で、これは右クリックメニュー・ショートカット・
ツールバーから呼び出したその瞬間に、そのタブ1つへのアクセスだけを許可するものです。操作して
いないページでは何も動きません。

呼び出されたときは、モザイク・ぼかし・塗り・枠を置くためにページの構造を読みます。読み取りは
ローカルで完結し、その結果がブラウザの外に出ることはありません。

## 変更

このポリシーを変更する場合は、下記リポジトリのこのファイルに反映します。
